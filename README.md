 # Superstore Sales Dashboard - Power BI

## Project Overview
This project analyzes Superstore sales data using Power BI. The dashboard provides insights into sales performance, profit trends, regional sales distribution, product performance, and order quantity.

## Objectives
- Analyze overall sales and profit.
- Identify top-performing products and categories.
- Compare sales across different regions.
- Track monthly sales trends.
- Provide detailed transaction-level analysis.

## Tools Used
- Power BI
- Superstore Dataset
- Data Visualization
- Data Analytics

## Dashboard Features

### Page 1: Sales Dashboard
- Total Sales: 2.30M
- Total Profit: 286.40K
- Total Order Quantity: 38K
- Sales by Region Analysis
- Product Sub-Category Distribution
- Monthly Sales Trend
- Top 10 Products by Order Quantity

### Page 2: Detailed Sales Data
- State-wise and City-wise sales records
- Product details
- Order quantity analysis
- Date-wise sales information
- Detailed transaction table

## Key Insights
- West region generated the highest sales.
- Total sales exceeded 2.29 million.
- Total profit reached 286 thousand.
- Phones and Chairs were among the top-performing sub-categories.
- Monthly sales showed significant growth in the final quarter.
